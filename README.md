# Forex Pro — SMC + ICT + Volume Profile

Pine Script v5 индикатор и стратегия для TradingView, реализующие объединённую
методику Lewis Kelly (автоматическая структура рынка) и Faiz SMC (ICT + Fixed
Range Volume Profile) для торговли на Форекс.

## Файлы

| Файл | Назначение |
| --- | --- |
| `forex_smc_ict_vp.pine` | Основной индикатор: разметка структуры, VA, FVG, сигналы входа. |
| `forex_smc_ict_vp_strategy.pine` | Стратегия для бэктеста и статистики (Net Profit, Profit Factor, Drawdown). |

## Установка в TradingView

1. Откройте вкладку **Pine Editor** внизу графика.
2. Вставьте содержимое `forex_smc_ict_vp.pine`.
3. Нажмите **Save** → **Add to chart**.
4. Для проверки прибыльности повторите шаги с файлом `*_strategy.pine` и смотрите вкладку **Strategy Tester**.

## Реализованная логика (соответствие ТЗ)

### 1. Структура рынка (Lewis Kelly)
- Иерархия ТФ: HTF (по умолчанию 4H), MTF (15M), LTF (текущий ТФ графика, рекомендуется 1M/5M).
- Swing High/Low — через `ta.pivothigh` / `ta.pivotlow` с настраиваемой глубиной (параметр `MTF Swing Length`).
- **BOS** (Break of Structure) — подтверждение текущего тренда.
- **CHoCH** (Change of Character) — первый слом в противоположную сторону (смена bias).
- **Фильтр фитилей** — `Только body breaks` сравнивает `close`, а не `high/low`.

### 2. Контекст дня — Volume Profile (Fixed Range)
- Окно сессии: 18:00 → 08:55 NY (параметр `Окно профиля`, поддерживает переход через полночь).
- Строится вручную по тиковому объёму (`volume`), разбивается на бины (по умолчанию 200; ТЗ — 1000, можно поставить).
- Value Area Volume — 70% (настраивается).
- На графике рисуются **VAH (красный)**, **VAL (зелёный)**, **POC (жёлтый пунктир)** и заливка VA.

### 3. Поиск зоны
- В дашборде показывается расположение цены: **Выше VAH / Внутри VA / Ниже VAL**.
- Сигналы в логике настроены так, что:
  - **Failed Auction Long** — цена ушла ниже VAL и закрылась обратно внутри VA.
  - **Failed Auction Short** — зеркально через VAH.
  - **Breakout Long/Short** — закрепление за VAH/VAL (два последовательных close).

### 4. Сигнал ICT
- **Fair Value Gap (FVG)**: строится по классике (разрыв между `high[2]` и `low[0]` для бычьего). Фильтр по минимальному размеру × ATR.
- **MSS (Market Structure Shift)** — пробой последнего LTF-пивота.
- В настройках можно требовать оба подтверждения при входе.

### 5. Подтверждение входа
Стрелка LONG/SHORT появляется только когда одновременно:
1. **Bias MTF** = нужная сторона (BOS/CHoCH).
2. Сработал один из сетапов — Failed Auction **или** Breakout.
3. Есть активный FVG (если включена опция).
4. Подтверждён MSS (если включена опция).
5. Текущее время — внутри Kill Zone (London или NY).
6. Расчётный R:R ≥ заданного минимума.
7. Прошёл cooldown с прошлого сигнала той же стороны.

## Улучшения сверх ТЗ для повышения прибыльности

| Улучшение | Зачем |
| --- | --- |
| **Kill Zones** (London 02:00–05:00, NY 07:00–10:00 NY) | Отсекает торговлю в низколиквидных часах, где много ложных пробоев. |
| **Опциональный HTF EMA-фильтр** | Позволяет входить только по направлению старшего тренда — повышает win-rate. |
| **Cooldown между сигналами** | Предотвращает серийные перевходы по одной и той же зоне. |
| **Минимальный R:R** | Автоматически отфильтровывает невыгодные сетапы (SL слишком далеко, TP слишком близко). |
| **TP = противоположная граница VA** (по ТЗ) + альтернативы RR-multiple / ATR-multiple | Гибкость под разные рынки. |
| **ATR-based SL** | SL выставляется с буфером к ближайшему экстремуму — защита от свипов. |
| **Body-break фильтр** | Снижает число ложных BOS/CHoCH. |
| **Мин. размер FVG × ATR** | Выкидывает шумные микро-FVG. |
| **Cooldown лимит + pyramiding=0** в стратегии | Стабильная статистика бэктеста. |
| **Дашборд + фоновая подсветка bias** | Мгновенная визуальная валидация контекста перед входом. |
| **Отдельная Strategy-версия** | Позволяет численно оценить прибыльность (Profit Factor, Sharpe, DD) до реальной торговли. |

## Воркфлоу использования

1. **Утром (до 09:00 NY)** индикатор завершает построение Value Area по ночной сессии.
2. **Смотрите bias** в дашборде: BULL / BEAR. Торгуете только в его сторону.
3. **Ждёте появления стрелки** — индикатор уже учёл все фильтры.
4. **SL/TP пунктирные линии** рисуются автоматически на баре сигнала.
5. **Алерты** — настройте через «Create alert» → `LONG Signal` / `SHORT Signal`, чтобы получать уведомления.

## Ограничения

- Forex volume — тиковый, а не реальный. Для Forex это стандартно и работает как прокси.
- `request.security` c MTF пивотами подтверждает пивот через `swingLen` баров (нет перерисовки на live).
- `rowSize = 1000` нагружает Pine-движок — если индикатор не успевает загружаться, уменьшите до 200–500.
- Стратегия использует `process_orders_on_close=true` — симулирует вход по close сигнального бара; в реальной торговле учитывайте спред.

## Параметры тонкой настройки для оптимизации

Прогоните стратегию в бэктесте, варьируя:
- `swingLen` 3…8
- `slAtrMult` 1.0…2.5
- `minRR` 1.5…3.0
- `fvgMinATR` 0.1…0.5
- `cooldownBars` 5…20
- Вкл/выкл `useHTFFilter`, `requireFVG`, `requireMSS`

На выходе TradingView покажет Net Profit, Profit Factor, Max Drawdown и Win Rate — выберите конфиг с PF ≥ 1.5 и DD ≤ 15%.
